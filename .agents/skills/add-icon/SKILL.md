# Icons: Lucide only

The window uses [Lucide](https://lucide.dev) (ISC), drawn at stroke 1.75 like
Hex. Do not mix other icon sets and do not hand-draw SVG paths. `src/ui/icons.rs`
is generated: never edit it.

## Add one

1. Add the Lucide name (kebab-case, e.g. `shield-check`) to `NAMES` in
   `scripts/lucide-icons.py`.
2. `python3 scripts/lucide-icons.py` (needs network: it downloads the pinned
   `lucide-static` release from unpkg and fails on an unknown name).
3. Use it as `icons::SHIELD_CHECK` (upper case, `-` becomes `_`).

## Use it

- Sidebar row: `SidebarRow::new(label).icon(&icons::HISTORY)`.
- Button: `Button::new(label).icon(&icons::COPY)`.
- Setting row: `setting_row(key, k, &icons::BELL, title, desc, control)`.
- Anywhere else: `rune::icon(&icons::X, 16.0).color(k.c.icon_muted)` (18 for rows,
  16 inline, 24 inside the status badge). Wrap a decorative icon in `.a11y_hidden()`.
- Tinted state icons (status, event level) take the status colour; see
  `hero::status_icon` and `activity::level_icon` and their tests: each state
  should have its own icon.

Check the result with `make snaps` (see `relink-verify`).
